# Nhật ký học LibraryHub

## Cấu trúc CSDL và dữ liệu mẫu

### Đã thực hiện
- Tạo migration cho categories, authors, books và author_book.
- Liên kết sách với thể loại bằng khóa ngoại.
- Tạo bảng nối sách và tác giả.
